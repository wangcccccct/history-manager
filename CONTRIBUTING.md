# Contributing

## Development

This extension uses plain JavaScript, HTML, and CSS. It has no dependency installation or build step.

1. Clone the repository.
2. Open `chrome://extensions` in Chrome and enable **Developer mode**.
3. Select **Load unpacked** and choose the repository directory.
4. After editing files, use **Reload** on the extension card and try the affected behavior.

## Changes

- Keep changes focused and update the README or privacy policy when behavior or data handling changes.
- Do not commit browser profiles, extension storage, passwords, private keys, or browsing data.
- Include a short description of the change and the manual checks performed when opening a pull request.
- Preserve the existing attribution to the upstream Hide My History project.

## Licensing

The repository does not yet have a selected license. Before submitting code intended for redistribution, check with the maintainers about the licensing terms for this derivative project and its upstream source.
